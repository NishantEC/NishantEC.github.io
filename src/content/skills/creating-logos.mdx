An agent skill for turning a clear product brief into a small set of logo directions worth reviewing.
It starts with the product, audience, and constraints, then makes the trade-offs visible instead of handing back a single unexplained mark.

<Install command="npx skills add NishantEC/skills --skill creating-logos" />

## what it produces

Each direction has a visual register, a reason it fits the brief, and enough detail to compare it with the others. The goal is not decoration; it is a mark a product can grow around.

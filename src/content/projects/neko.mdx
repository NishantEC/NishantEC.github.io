Neko brings apps, files, agent sessions, and Codex tasks into one command palette. It keeps approval safeguards, follow-ups, scheduling, and compact task activity close to the action rather than scattered across separate tools.

The point is a fast way to start and supervise work without losing the context of what is already running.
